## 二、设计目标

1. **一个页面控制全部** — 不打开 QMT、不改代码、不敲命令
2. **总闸物理级可靠** — 关了就是关了，任何子模块不能绕过
3. **减仓单永不拦截** — 熔断中也可以卖，只堵买入不堵卖出
4. **分层预警** — 黄→橙→红三级，提前告警不要到红才动
5. **防误操作** — 开启需确认码，紧急停止5秒倒计时可撤回

## 四、分级预警机制

对标 FIA 2024 分层预警 + 私募三色灯实践：

| 级别 | 颜色 | 触发条件 | 动作 |
|------|:---:|------|------|
| 正常 | 🟢 绿 | 所有指标正常 | 正常交易 |
| 关注 | 🟡 黄 | 日亏损>2% / 连续亏损2笔 / 行业>20% / 仓位>70% | 钉钉提醒，不限制 |
| 警告 | 🟠 橙 | 日亏损>3.5% / 连续亏损3笔 / 行业>23% / 仓位>85% | 暂停新开仓，只允许减仓 |
| 熔断 | 🔴 红 | 日亏损>5% / 连续亏损5笔 / 行业>25% / 总闸关闭 | 撤所有挂单，禁止一切买入 |

**核心原则**：橙和红状态下，**卖出/减仓/止损单永不拦截**。

## 五、总闸控制器设计

```python
# master_switch.py — 独立模块, 零依赖

class MasterSwitch:
    """全局总闸 — 所有交易通道的下单前唯一检查点"""

    _STATE_FILE = r"D:\quant_framework\master_switch.json"

    def __init__(self):
        self.real_enabled = False      # 实盘总闸 (默认关!)
        self.sim_enabled = True        # 模拟盘总闸
        self.emergency_stop = False    # 紧急停止 (手动触发)
        self._load()

    def can_buy(self, channel="sim") -> bool:
        """买入前检查 — 被所有通道调用"""
        if self.emergency_stop:
            return False
        if channel == "real":
            return self.real_enabled
        return self.sim_enabled

    def can_sell(self) -> bool:
        """卖出前检查 — 减仓永不拦截"""
        return True  # ← 行业铁律

    def emergency_halt(self, operator="老板"):
        """紧急停止 — 一键全断"""
        self.emergency_stop = True
        self.real_enabled = False
        self.sim_enabled = False
        self._save()
        self._audit(operator, "EMERGENCY_HALT")

    def enable_real(self, operator="老板", confirm_code=""):
        """开启实盘 — 需确认码"""
        if confirm_code != self._get_confirm_code():
            return False
        self.real_enabled = True
        self._save()
        self._audit(operator, "REAL_ENABLED")
        return True
```

**所有交易通道统一调用**：

```
QMT 策略:
    if not master_switch.can_buy("real"): return  # 不进 passorder

paper_engine:
    if not master_switch.can_buy("sim"): return   # 不进 place_order

live_trader:
    if not master_switch.can_buy("real"): return  # 不进 send_buy_order
```

## 九、关键设计决策

| 决策 | 理由 |
|------|------|
| 总闸默认关 | 对标私募：实盘开启需要主动确认，防误操作 |
| 减仓永不拦截 | FIA 2024 铁律，也是行业红线 |
| 独立模块不嵌业务 | 对标 vnpy RiskManager 独立进程设计 |
| 写磁盘持久化 | Flask 重启不丢状态 |
| 确认码防误开 | 对标对冲基金物理钥匙+软件确认双因素 |
