## 信号表 → 选股器 (ml-signals) 字段

```
signal_table.json 字段          ml-signals 列
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
symbol                         代码
name                           名称
industry                       行业
consensus                      来源 (L+X+R/L+X/LGBM/XGB/打板/反转/因子)
current_price/close            现价
current_change_pct/change_pct  涨跌
lgbm_score (归一化)             L
xgb_score (归一化)              X
ridge_score (归一化)            R
combined_score                 综合
signal                         等级
position_pct                   仓位
stop_loss                      止损
auto_enabled                   操作 (自动/已批/待批/拦截)
decision                       名称后缀 (✅共振/⚠️分歧)
```

## 信号表 → 终端信号卡 (terminal) 字段

```
signal_table.json 字段          terminal 日线信号卡
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
combined_score                 综合分数字
symbol                         代码
name                           名称
lgbm_score/xgb_score           共识点 (●)
signal                         等级 L5-L1
change_pct                     涨跌%
stop_loss                      止损价
take_profit                    止盈价
industry                       行业 (带色块)
quality_score                  质量分 Q{qs}
decision                       决策标签 (共振/分歧/降级)
auto_enabled                   按钮 (自动/批准/忽略)
```
