从信号生成 → 候选入池 → QMT监控 → 实时确认 → 下单执行
1
收盘后: 日线扫描 → 封板质量评分
Flask 日线批处理: 5201只A股 → 检测今日涨停票 → 评分(开盘位置×量比×炸板×板块联动×封板时间)
signals/daban.py → score_board_quality(df)
↓ 输出: 3-20 只候选票 + 封板质量分(0-100)
2
写入 auto_trade_plan.json
候选票 + 封板质量分 + 止损价 → 写入 plan → QMT 3秒后自动加载
generate_signal_table.py → auto_trade_plan.json
↓ 输出: plan.stocks["sz002208"] = {stop_loss, take_profit, signal_types:["打板追封"]}
3
次日开盘: QMT 加载候选池
QMT 策略启动 → 读 plan → 构建 _fast_cache → 96只候选票进入监控列表
qmt_full_strategy.py → _load_plan() → _build_fast_cache()
↓ 输出: _fast_cache["sz002208"] = (enabled=True, pos=3%, stop=18.81, signal=打板追封)
4
盘中: tick 级检测 — 封板确认
每笔 tick 推送到 handle_bar() → 检测:
✅ 现价 == 涨停价? → 封板成功
✅ 封板时间 < 10:00? → 早盘最强
✅ 封单量 > 流通盘 3%? → 强封
✅ 未炸板或 30 分钟内回封? → 回封加分
→ 四项全过 → 触发买入信号
qmt_full_strategy.py → handle_bar() → signal_name = "打板追封"
5
下单执行 & 推送信号
① passorder(23, ...) → QMT 快速下单 (实盘)
② POST /api/qmt/signal → Flask 记录 + 前端展示
③ 前端 ⚡盘中信号 显示: 🎯 打板 + 批准按钮
passorder() + FLASK_URL
